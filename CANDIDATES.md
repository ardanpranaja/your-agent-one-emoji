# Candidates considered

Shortlist for the one-emoji portrait of an AI agent that fixes its own bugs
at 4am and keeps going. The owl won.

- 🦉 **Owl — chosen.** Awake when everyone else sleeps, hunting bugs in the
  dark, wise without being a robot. Reads instantly at small size.
- 🐛 Bug — says what the agent hunts, but not what the agent *is*; reads
  as the problem, not the fixer.
- 🔧 Wrench — says "fixes things", but it is a tool, not a character, and
  half the field would reach for a tool first.
- 🌙 Crescent moon — captures the 4am shift, but says nothing about
  working, watching, or fixing; too quiet for an agent that ships.
- 🧠 Brain — captures thinking, but it is generic AI shorthand and it
  says nothing about the night shift or the grind.
